Lead Operations & AI Routing

SwiftLead — Tier 1 Starter (Instant AI Intake & Smart Routing)

Captures inbound website enquiries via webhook, enforces strict input validation, generates atomic daily sequential Lead IDs, classifies intent and urgency via OpenRouter LangChain AI, automatically assigns the lead to the sales agent with the lowest workload, records the prospect in Airtable, and fires dual personalized emails.

Engineering Highlights

  • check_circle Zero-Latency Validation: Rejects malformed requests or invalid email formats immediately with HTTP 400 and structured JSON error response before executing downstream API calls.
  • check_circle Sequential Atomic Lead IDs: Queries today's existing records in Airtable to dynamically compute and increment the sequence number format (e.g. 20260901-A01), ensuring clean auditability.
  • check_circle Structured AI Extraction: Uses LangChain Agent connected to OpenRouter (nvidia/nemotron-3-super-120b-a12b:free) with temperature 0.2 to categorize intent (Buying, Renting, Selling, Viewing) and assign urgency (High, Medium, Low).
  • check_circle Load-Balanced Routing: Dynamically checks the Agents table in Airtable, filters available reps, skips managerial roles, and assigns the prospect to the agent with the lowest active workload, incrementing their counter atomically.
  • check_circle Personalized AI Acknowledgement: Crafts a warm, human customer receipt referencing their specific inquiry details while establishing a strict 1-business-hour response time guarantee.

SLA Enforcement & Escalation

SwiftLead — Tier 2 Professional (Slack SLA Monitor & Escalation Engine)

An asynchronous, state-persistent watchdog that monitors lead response times. Triggered immediately upon lead creation in Airtable, it looks up the assigned sales rep on Slack, sends a rich direct notification, tracks a strict 2-hour SLA window, checks status, triggers an urgent reminder, and escalates directly to the Sales Manager if unattended.

arrow_forward

arrow_forward

arrow_forward
notifications_active Slack Reminder Urgent Follow-Up Ping
arrow_forward
hourglass_bottom Wait 1 Hour Grace Period Timer
arrow_forward

Engineering Highlights

  • check_circle Persistent Asynchronous Execution: Leverages n8n's native Wait node state persistence, allowing long-running multi-hour timers to survive worker reboots without losing execution memory or lead state.
  • check_circle Direct Slack API Integration: Performs automated user lookups via users:lookupByEmail to map Airtable agent emails directly into Slack user IDs for frictionless direct messaging.
  • check_circle Two-Tiered Graceful Warning: If the rep updates the lead status to "Contacted", "In Progress", or "Closed" within the 2-hour window, the workflow gracefully terminates immediately via a NoOp node.
  • check_circle Zero-Leakage Manager Escalation: If a lead remains uncontacted after 3 total hours, the workflow queries Airtable for the "Sales Manager", resolves their Slack profile, and fires a high-priority escalation alert with complete lead provenance.

DocXpress — Autonomous Invoice Processing & AP Pipeline

An end-to-end intelligent document processing system that monitors inbound emails for invoices, parses PDF binary documents, validates against duplicates in Airtable, extracts structured accounting fields via OpenRouter LLMs with JSON schemas, records line items in CRM, and delivers instant Slack and Email receipts.

Engineering Highlights

  • check_circle Airtable Duplicate Shield: Checks incoming file signatures against the database before running LLM inference. If a duplicate invoice is detected, it triggers a warning email to the finance team and prevents database clutter.
  • check_circle Strict Zero-Shot LLM Schema Enforcement: Uses OpenRouter (nvidia/nemotron-3.5-lightning:free) with LangChain Structured Output Parser to extract 10 key financial fields (Vendor, Invoice #, Date, Due Date, Subtotal, Tax, Total, Currency, Confidence).
  • check_circle Dynamic Confidence Scoring: Computes an extraction confidence index (0.0 to 1.0) embedded into the record to flag low-confidence invoices for human review.
  • check_circle Instant Cross-Platform Receipts: Sends formatted HTML emails with financial breakdown tables and confidence score badges, alongside real-time Slack channel notifications for immediate team visibility.

ThreatPulse — Automated Cyber Intelligence & RSS Feed Engine

An automated scheduled cybersecurity monitoring pipeline. Regularly pulls live RSS feeds from authority sources (The Hacker News, CVE feeds, security research advisories), cross-references article GUIDs against a Google Sheets state database to prevent duplicates, and syndicates real-time threat alerts to security team channels.

Engineering Highlights

  • check_circle Zero-Noise Deduplication: Queries a central Google Sheets registry (rsshub) by article guid. If the advisory has already been syndicated, it is discarded immediately to prevent alert fatigue.
  • check_circle Real-Time Threat Ingestion: Automatically normalizes article author, published timestamp, threat summary snippets, and image enclosures across multiple security feeds.
  • check_circle Multi-Channel Broadcast: Automatically formats and broadcasts newly verified zero-days, CVE exploits, and campaign reports to instant messaging bots and SOC channels.
